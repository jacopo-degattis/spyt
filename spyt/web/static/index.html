Move a Spotify playlist
to YouTube Music.

Paste a link, add your credentials, and let Spyt match every track.

Runs locally. Your credentials never leave this machine.

Public or private

A link, spotify:playlist:… URI, or a bare playlist ID all work.

Spotify cookies

Used to read your playlist.

Required
Drop a cookies file or browse cookies.txt · cookies.json
or paste the contents

How do I get this?
  1. Log in at open.spotify.com.
  2. Export the site cookies with Get cookies.txt LOCALLY or Cookie-Editor.
  3. Drop the exported cookies.txt or cookies.json above.

YouTube Music headers

Used to create the playlist.

Required
Drop a headers file or browse Headers, cURL, or JSON
or paste the contents

How do I get this?
  1. Log in at music.youtube.com.
  2. Open DevTools → Network and open any playlist.
  3. Right-click the browse request → Copy → Copy request headers.
  4. Save them to a file (or paste them above).
